# Brinda Personalizados — site

Site estático (HTML, CSS e JavaScript), sem etapa de build.

- `index.html` — página inicial · `catalogo.html` — catálogo com solicitação de orçamento
- `js/config.js` — WhatsApp, e-mail, endereço e endereço do sistema de orçamentos
- `js/produtos.js`, `js/produtos-asia.js`, `js/produtos-xbz.js` — produtos e categorias (sem preços)
- `img/` — fotos dos produtos, categorias e logo

Para atualizar o site: altere os arquivos e envie para a branch `main`; o GitHub Pages republica sozinho.
